This folder contains all code and data files needed for
regression/correlation/cluster analysis/CPA.\
\
- ***UtilityFunctions.R:*** functions needed for all analyses\
- ***Regression & Correlation.R***: code for regression and correlation\
- ***Cluster&CPA.R***: code for cluster analysis and CPA\
- ***promis_global_physical/mental_conversion_table.csv***: table used
to convert PROMIS global health scores to T-scores\
- ***generate_gt_tables.R***: code for generating GT tables for original
and scaled regression analysis results (need to first download result
data frames and run this code on your local computer, and then upload
generated GT tables to Seven Bridges)\
- ***CovData*** folder\
- ***run_sleep_analysis_codefromElias.R***: code from Elias to get
covariates (month, numrecs_in_window, days_between_visits)\
- ***training_set_participant_ids_05312024.txt***: training ids (can be
found in Mobashir's workspace (eda_mobashir_duke) in Seven Bridges)\
\
\
Please first run "***run_sleep_analysis_codefromElias.R****" to get the
covariate file for each digital measure.*
